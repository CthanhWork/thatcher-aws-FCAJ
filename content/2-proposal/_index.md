# Internship Proposal

## Introduction

My name is **Hoang Chi Thanh**, and I am honored to join the **First Cloud Journey (FCAJ)** internship program at **Amazon Web Services Vietnam Co., Ltd.** During my internship period from **17/04/2025 to 10/07/2026**, I aim to strengthen both my technical foundation and practical engineering mindset through hands-on cloud learning, real-world problem solving, and continuous self-improvement.

As a student with strong interest in **Fullstack Development** using **Spring Boot** and **ReactJS**, as well as modern **AI applications** such as **Retrieval-Augmented Generation (RAG)** and **Computer Vision**, I see FCAJ as an important opportunity to bridge academic learning with production-oriented cloud practices. I am excited to explore how AWS services can support scalable, secure, and intelligent applications in real business scenarios.

## Objective

The main objectives of my internship are:

- **Master core AWS services** including **IAM, VPC, EC2, S3, RDS, and Lambda**.
- **Learn cloud security best practices**, especially in identity management, least-privilege access control, network isolation, and secure service configuration.
- **Successfully deploy a personal project or a technical workshop on AWS** to demonstrate practical understanding of cloud architecture, deployment workflows, and operational thinking.

## Personal Project Integration

During the internship, I plan to apply the AWS knowledge I gain to my current project, **H-Smart**, an **AI-powered marketplace for second-hand home appliances**. The goal of H-Smart is to improve the experience of buying and selling pre-owned appliances by combining marketplace features with AI-based intelligence.

I expect AWS to support this project in several practical ways:

- **Amazon S3** can be used for storing product images and other static assets reliably and cost-effectively.
- **Amazon RDS** can serve as the primary managed database for transactional data such as users, products, orders, and listing details.
- **Amazon EC2** can host backend or supporting services when needed during experimentation and deployment.
- **AWS Lambda** can be explored for lightweight background tasks, event-driven processing, or automation workflows.
- **AWS Bedrock** is a promising direction for experimenting with **RAG-based AI features**, such as intelligent product recommendations, question answering, or semantic search in marketplace data.

By integrating AWS services into H-Smart, I aim to better understand how cloud-native components can improve system scalability, maintainability, and practical AI adoption.

## Learning Roadmap

To ensure focused progress, I will follow a **4-week intensive learning roadmap**:

- **Week 1: Foundation and Networking**
  Learn AWS fundamentals, IAM concepts, user and role management, VPC basics, subnets, route tables, internet gateways, and security groups.

- **Week 2: Compute and Storage**
  Practice launching and managing EC2 instances, understanding key pair access, configuring storage, and working with Amazon S3 for object storage and static content handling.

- **Week 3: Databases and Content Delivery**
  Explore Amazon RDS for managed relational databases, understand data persistence in cloud applications, and study CDN-related concepts for faster and more efficient content delivery.

- **Week 4: Serverless and Finalization**
  Learn the serverless model with AWS Lambda, review integrated cloud architecture patterns, and finalize a deployable outcome such as a personal project component or a workshop implementation on AWS.

## Commitment

I am committed to contributing **48 hours per week**, equivalent to **6 days per week** and **8 hours per day**, throughout the internship. I will maintain a disciplined and proactive learning attitude, complete assigned tasks responsibly, and continuously improve through documentation and reflection.

In addition, I commit to producing:

- **High-quality translated blogs** that help reinforce technical understanding and share useful cloud knowledge clearly.
- **Technical workshop outputs** with structured documentation, practical screenshots, and clear implementation steps.
- **Consistent worklog updates** to track my learning progress, technical challenges, and achieved results during the internship.

## Expected Outcome

By the end of this internship, I expect to gain a solid practical foundation in AWS, improve my cloud security awareness, and build stronger confidence in deploying modern web and AI-related applications on cloud infrastructure. More importantly, I aim to transform what I learn in FCAJ into tangible value through both my personal project and the technical content I produce during the program.
